## 充值前的三句话

1. **账号标识填对了吗？** 阿里云国际填 UID，腾讯云国际填账号 ID，AWS 填登录账号；Azure 和 Google Cloud 先找顾问确认。
2. **到账金额对得上吗？** 订单上的应付 USDT 是对方要收到的数，手续费另算。
3. **包月资源续上了吗？** 余额够不等于自动续费，到期前单独确认。
