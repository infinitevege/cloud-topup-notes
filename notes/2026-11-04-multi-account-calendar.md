# 手上有好几个云账号：用一张表管住余额和到期日

> **一句话结论：** 账号超过三个，就别再靠记忆了。一张表、每周看一次，能挡住绝大多数漏充和欠费。

做海外业务久了，账号会越来越多：一个阿里云国际跑网站，一个腾讯云国际跑游戏服，一个 AWS 放数据库，可能还有测试用的。真正出事往往不是因为没钱，而是**没人记得哪个账号快没钱了**。

## 表头就这几列

| 列 | 填什么 | 为什么要记 |
| :--- | :--- | :--- |
| 平台 | 阿里云国际 / 腾讯云国际 / AWS / Azure / Google Cloud | |
| 账号标识 | UID、账号 ID、AWS 登录账号、订阅或结算账户信息 | 充值时要填，填错就充到别的账号 |
| 用途 | 官网、游戏服、测试…… | 判断优先级 |
| 负责人 | 一个具体的人名 | 出问题时找谁 |
| 当前余额 | 每周更新一次 | |
| 日均消耗 | 最近 7 天平均 | 用来算还能撑几天 |
| 可用天数 | 余额 ÷ 日均消耗 | 低于 7 天标红 |
| 包年包月到期日 | 最近一个到期的资源 | 余额充足不等于自动续费 |
| 下次计划充值日 | 根据可用天数倒推 | |

## 每周一次的「五分钟巡检」

1. 依次登录每个账号的费用中心，更新「当前余额」和「日均消耗」。
2. 表格自动算出「可用天数」，标红的行优先处理。
3. 看一眼「包年包月到期日」，30 天内到期的确认续费设置。
4. 需要充值的，按 [这次该充多少](2026-11-04-estimate-top-up-amount.md) 的方法算金额。

## 几个小经验

- **账号标识列单独核对一次。** 把每个账号登录后看到的标识和表里的逐个比对，一次就够，以后省很多事。账号标识的位置见 [充值前如何查找账号标识](https://www.clouddage.com/resources/find-account-id-before-top-up)。
- **用途为「测试」的账号定期清理。** 不用的资源及时释放，别让测试账号悄悄扣钱。
- **余额告急的账号，提前一天处理。** 余额耗尽后，按量资源可能被停机，具体规则因平台而异；被暂停后的处理办法见 [账号被暂停怎么办](https://www.clouddage.com/resources/cloud-account-suspended-what-to-do)。

## 新增账号时

新开账号可以在云大哥的 [支持平台](https://www.clouddage.com/platforms) 里选择对应平台办理开户。交付后第一时间把账号标识、负责人写进这张表，再去开 MFA。
