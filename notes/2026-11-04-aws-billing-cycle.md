# AWS 什么时候扣钱？月结周期、预估费用与充值时机

> **一句话结论：** AWS 的费用按自然月累计，月初结算上个月。月底前看一眼本月预估费用，月初扣款前把余额准备好。

从阿里云国际、腾讯云国际转到 AWS 的同学，常常不习惯 AWS 的计费节奏：前两家以按量计费、实时扣余额为主，而 AWS 是**先用后结**。

## 问：AWS 的账期是怎么算的？

- 账期是**自然月**（按 UTC 时间），每月 1 日到月底。
- 一个月里用掉的费用会持续累计，在 Bills 页面可以看到**本月截至目前**的费用。
- 月份结束后，AWS 会生成上个月的正式账单，并按账号的付款方式结算。

渠道开通的账号，余额与扣款的具体方式以服务方说明和订单约定为准。

## 问：本月大概要花多少，在哪看？

在 Billing and Cost Management 控制台：

1. **Bills**：看本月截至目前的费用，按服务展开。
2. **Cost Explorer**：开启后可以看到按天的趋势，并给出本月的预测值。
3. **AWS Budgets**：设一个月度预算，实际或预测达到阈值时发邮件提醒。

默认只有根用户能看账单。日常用 IAM 用户的话，需要根用户先开启「IAM 用户访问账单信息」。根用户本身一定要开 MFA，方法见 [云账号 MFA 设置手册](https://www.clouddage.com/resources/mfa-setup-alibaba-tencent-aws)。

## 问：那什么时候充值最合适？

我们的习惯是：

| 时间点 | 做什么 |
| :--- | :--- |
| 每月 20 日前后 | 看 Cost Explorer 的本月预测，估算月底总额 |
| 月底前几天 | 按预测金额 + 一定余量办理充值 |
| 次月初 | 确认上月账单金额，与充值记录对一遍 |

这样月初结算时余额是够的，也不会提前太久把钱压在账号里。

## 问：有什么费用经常超出预期？

- **数据传输**：出网流量、跨可用区、跨区域都单独计费。
- **NAT 网关**：按小时和处理的数据量收费，开着不用也在计费。
- **忘关的资源**：测试用的 EC2、未挂载的 EBS 卷、闲置的弹性 IP。

## 怎么办理

AWS 账号在云大哥支持 [网页自助充值](https://www.clouddage.com/top-up)，填写 AWS 登录账号即可；只受理通过云大哥开通的账号。还没有账号的，可以看 [AWS 开户说明](https://www.clouddage.com/platforms/aws)。
